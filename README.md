HR Data Analysis using Python

This project focuses on Exploratory Data Analysis (EDA) on HR employee attrition data using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

Project Objectives:
- Analyze employee attrition patterns
- Understand department-wise attrition
- Analyze overtime, gender, and marital status impact
- Visualize HR insights using charts

Tools & Libraries:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Key Insights:
- R&D department showed the highest attrition
- Employees aged 25–34 had the highest attrition
- Single employees showed higher attrition
- Overtime employees showed comparatively higher attrition
